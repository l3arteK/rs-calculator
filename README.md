#  Aplikacja do obliczania optymalnego rozstawu strzemion

Kalkulator do obliczania optymalnej  ilości strzemion w środkowym przęśle oparty na **Pygame** oraz na wcześniej opracowanym algortymie.

##  Jak używać
Aby z niej skorzystać, wystarczy pobrać skompilowany już plik `.exe` i uruchomić go lokalnie na komputerze.

[EN]
#  Optimal Stirrup Spacing Calculator

Calculator for determining the optimal number of stirrups in the central span, based on Pygame and a previously developed algorithm.

##  How to use
To use it, simply download the already compiled `.exe` file and run it locally on your computer.
