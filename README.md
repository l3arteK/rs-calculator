#  Aplikacja do obliczania optymalnego rozstawu strzemion

Prosta aplikacja desktopowa oparta na **Pygame**, wykorzystująca opracowany wcześniej algorytm do obliczania najbardziej optymalnego rozstawu strzemion.

##  Jak używać
Aby z niej skorzystać, wystarczy pobrać skompilowany już plik `.exe` i uruchomić go lokalnie na komputerze.

[EN]
#  Optimal Stirrup Spacing Calculator

A simple desktop application based on **Pygame**, using a previously developed algorithm to calculate the most optimal arrangement of stirrups.

##  How to use
To use it, simply download the already compiled `.exe` file and run it locally on your computer.
